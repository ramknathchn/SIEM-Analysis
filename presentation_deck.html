SLIDE 02 / PROPOSED SOLUTION

Local-First UEBA SIEM & Explainable AI Engine

Combining OCSF schema normalization, 90-day statistical baselines, 5-hop graph CTEs, and AI incident synthesis.

🌐

1. Unified Multi-Cloud OCSF 1.1 Normalizer

Standardizes raw logs from AWS, Azure, GCP, and Okta into normalized OCSF 1.1, Splunk CIM, Microsoft Sentinel KQL, and Elastic ECS schemas.

Multi-Platform Ingestion
📈

2. 90-Day Statistical Baseline Engine

Calculates historical daily mean (μ), standard deviation (σ), and 30-minute session velocity spikes (+3σ) to isolate true anomalies.

Sliding Window Sessionizer
🕸️

3. SQLite 5-Hop Graph CTE & Canvas Node Graph

Runs a 5-hop recursive CTE query on caad_topology.db (1,050 entities, 2,593 edges) to render real-time visual blast radius graphs.

Blast Radius = ∑ ( Criticality × Sensitivity × 1/Hop_Depth )
🤖

4. Explainable AI & Sentiment Engine

Generates plain English summaries, maps MITRE ATT&CK paths (T1078.004, T1621), D3FEND tables, 1-click CLI playbooks, and analyst AI sentiment scoring.
